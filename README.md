# MoQT overhead

Resource measurements of IETF MoQT draft-22 implementations over raw QUIC,
covering Publisher, Subscriber and Relay processes on Linux.

This is an AI-powered research project. AI (OpenAI Codex) assisted with research,
experiment planning, implementation, execution, analysis and documentation.

- [Experiments](experiments/README.md): methods, results, data and reproduction instructions.
- [Publisher and Subscriber comparison](experiments/records/2026-11-22-endpoint-resources.md).
- [Research plan](experiment-plan.md) (Japanese).

These measurements describe Linux processes, not microcontroller RAM requirements.
